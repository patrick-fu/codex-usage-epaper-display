UsageInk first-run 与菜单栏状态机

问题：在不做成窗口应用的前提下，first-run、Codex 就绪、本机指标、BLE 绑定、wakeup_pin 明示同意、Initial/手动/自动 Refresh、以及 Mac 睡眠/断线恢复，怎样用一组正交字段和少量菜单动作覆盖，且非法动作能被说清？

待验证的产品假设（点场景或自由操作来打）
  1. 默认不自动写 pin：读到 wakeup_pin=0xFF 或已有非 0xFF 时，只记录，不进入待确认，更不会发写入。
  2. Codex 未就绪允许降级帧：未登录/未安装时仍可绑定并 Refresh；帧上写原因，绝不画 0%。
  3. 手动 Refresh 即使内容未变也强制整帧；自动 Refresh 内容未变则跳过。
  4. 多候选按广播名 + RSSI + 短 ID 选择，同时只绑一台，换设备必须先解绑。
